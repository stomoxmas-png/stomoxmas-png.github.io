# たけクイズ

スマホでゲーム感覚で学べる、子ども向けクイズアプリです。
国語・算数・理科・社会・英語・道徳の科目から、さらに細かいジャンルを選んでクイズに挑戦できます。

## 遊び方

1. 科目を選ぶ（国語・算数・理科・社会・英語・道徳）
2. ジャンルを選ぶ（例：国語 → 漢字・慣用句・ことわざ・文章）
3. ランダムに出題される5問に、選択肢をタップして回答
4. 「答えを見る」で正解・解説を確認 → 「次へ」で次の問題へ
5. 5問終わると結果画面。「もう一度」で再挑戦できる

## ローカルでの確認方法

このアプリは `fetch` で `data/` 配下のJSONファイルを読み込むため、`index.html` を直接ブラウザで開く（`file://`）と CORS エラーで動作しません。必ず簡易HTTPサーバー経由で開いてください。

```bash
cd "たけクイズ"
python3 -m http.server 8000
```

ブラウザ（またはスマホ実機・Chrome DevToolsのデバイスモード）で `http://localhost:8000` を開いてください。

## 技術スタック

- 素のHTML / CSS / JavaScript（ビルドツール不要）
- 問題データは `data/` 配下のJSONファイル
- 進捗・ハイスコアは端末内の `localStorage` に保存

制作ルールの詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。

## GitHub Pages での公開

1. GitHubリポジトリの Settings → Pages を開く
2. 「Branch」を `main` / `/(root)` に設定して保存
3. 数分後に `https://<ユーザー名>.github.io/take-quiz/` で公開される
